# Journal

One file a day, `YYYY-MM-DD.md`, written by the nightly gardener (and appended to by agents). Two sections, always in this order:

    # Tue Oct 20, 2026
    ## Work
    - what got built, decided or broke; what agents did (one line each, outcome first)
    ## Life
    - family, plans, errands, money, health (life scope only)

Work-scope agents see only `## Work`.
